# futures-terminal — 期货终端

> Android 手机本地运行的**期货监控 + 回测系统**。纯本地，策略不上传。
> 版本：v1.0.5（2026-08-11）
> 编译：GitHub Actions 云端（`.github/workflows/apk.yml`）

---

## 1. 核心原则

- **中央路由（RouteRegistry）** —— 所有事件统一调度
- **模块化** —— 每个模块独立文件
- **策略文件永不联网**
- **本地服务器只监听 127.0.0.1**
- **改文件前必须备份**

## 5. 数据源研究（关键结论）

### ✅ 可用
| 数据源 | 域名 | 日K | 分钟K |
|---|---|---|---|
| **新浪主源** | `stock2.finance.sina.com.cn` | ✅ | ✅ |
| **新浪备用** | `stock.finance.sina.com.cn` | ✅ | ✅ |

### ❌ 不可用
东财 push2his（被封）、同花顺（404）、腾讯（接口改版）、网易（502）、雪球（需登录）、百度（仅 agm）、通达信 TCP（协议未调通）

### 🚀 重大发现
**新浪 K 线不封 IP** —— 965 合约 17 秒拉完 811 个（84%），无限速。

**两个已修复的 Bug**：
1. **郑商所代码转换**：`sa609` → `sa2609`（**3 位补 2**）
2. **新浪返回判断**：先判 `var _x=` + `"d":` 再解析

## 6. 每日增量更新（推荐）

```bash
node server/update-kline.js 5   # 58秒增量，历史保留只追加
```

| 脚本 | 用途 | 用时 |
|---|---|---|
| `prefetch-daily.js` | 全量日K（首次/重建） | 17s |
| `prefetch-multi-slow.js` | 全量4H+1H | 3min |
| **`update-kline.js`** | **每日增量（推荐）** | **58s** |

**原理**：读缓存最后 K 线时间 → 拉新浪最新 → 只保留更新的 → 写入（旧历史最多留 500 根）。

## 7. EMA26 多周期策略（默认）

- **4H 定方向**：收盘价 > EMA26(4H) 只做多，< 只做空
- **1H 找入场**：上穿/下穿 EMA26(1H) + ATR 安全距离 + 连续3根确认 + 阳/阴线
- **减仓**：1H 跌破/突破 EMA26 减 1/3
- **清仓**：4H 跌破/突破 EMA26 清仓
- **仓位**：2% 风险预算 / 止损距离 × 10，最多 3 手

**验证结果**（agm 沪银，4H+1H，200根）：总收益 3.49%，交易 28 次，胜率 71.4%，最大回撤 0.71%

## 8. 关键坑

1. **浏览器缓存旧 JS** —— 前端 JS 加版本号 `?v=N`，改代码后必须更新
2. **新浪双域名降级** —— 主源失败自动切备用
3. **预取全部数据很慢** —— 用后台慢慢拉，不阻塞页面
4. **筛选默认只读缓存** —— 需实时传 `liveFetch=true`
5. **沙盒没有后台进程** —— `nohup`/`&`/`disown` 无效
6. **点"刷新行情"不再清 K 线缓存**（已修复）
